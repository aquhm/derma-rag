# PRD · 문제성 피부 메이크업 RAG

## 1. 한 줄 정의

문제성 피부와 관련된 질문을 받아, AI Hub 데이터셋 안에서 근거 문단을 찾고 **그 근거만으로** 답하는 로컬 질의응답 시스템.

## 2. 왜 만드는가

**표면 목적** — RAG 파이프라인을 처음부터 끝까지 직접 만들어 각 단계를 이해한다.

**이 데이터를 고른 이유** — 세 가지가 겹친다.

1. **정답지가 딸려 있다.** 질의응답 10,043쌍이 포함돼 있어 정확도를 감이 아니라 숫자로 잴 수 있다. 처음 만드는 RAG가 "잘 되는 것 같다"에서 멈추는 흔한 실패를 피할 수 있다.
2. **텍스트라 가볍다.** 이미지 데이터셋과 달리 디스크와 VRAM 부담이 없다. 16GB 환경에 맞는다.
3. **안전 설계를 실제로 요구한다.** 의료 인접 주제라 "지어내면 안 된다"가 추상적 원칙이 아니라 구체적 요건이 된다. 안전 장치를 넣는 이유를 체감할 수 있다.

## 4. 범위

### 하는 것

- 지식데이터를 문단 단위로 분할하고 임베딩해 색인을 만든다
- 자연어 질문에 대해 관련 문단을 검색한다
- 검색된 문단만을 근거로 답을 생성한다
- 답과 함께 근거 문단을 제시한다
- QA 10,043쌍으로 검색 정확도와 답변 정확도를 측정한다
- CLI로 조작한다

### 하지 않는 것

- 사진으로 피부 상태를 판별하지 않는다. **이 데이터셋에 이미지가 없다.**
- 진단하지 않는다. 증상 이름을 확정하는 출력을 만들지 않는다.
- 제품을 구매 링크와 함께 추천하지 않는다.
- 모델을 파인튜닝하지 않는다 (MEMORY.md D-002).
- 웹 UI를 만들지 않는다. M3 이후 선택 사항이다.
- 사용자 계정, 로그인, 이력 저장을 만들지 않는다.

## 5. 성공 기준

측정 가능한 것만 적는다. "잘 된다"는 기준이 아니다.

| 지표 | 목표 | 측정 방법 | 실측 |
|---|---|---|---|
| 답변 정확도 | 기준선 대비 개선 | 기대 답변과 생성 답변의 음절 2-gram F1 (`MEMORY.md` D-026) | 0.238 → **0.315** |
| 근거 없음 처리 | 100% | 검색 실패 시 생성으로 넘어가지 않는 비율 | 코드 분기로 강제 |
| 진단 표현 | 0건 | 금지 표현 5종 정규식 검사 (D-034에서 "의료 이용 판단" 추가) | 실사용 30건에서 0건 |
| 응답 시간 | 참고치만 기록 | 로컬 환경이라 목표를 걸지 않는다 | 질문 1건 3~6초 |

**Recall@5는 지표에서 뺐다.** 목표를 0.70으로 잡았으나 이 데이터셋에서는 측정 자체가 성립하지 않는다. 전량 9,031건에서 0.001이 나왔고, 이는 무작위 기대값 0.0008과 같은 수준이다. 질문과 주석된 근거가 두 다리 건너 연결돼 있기 때문이다. 근거는 `MEMORY.md` D-029.

**기준선을 먼저 만든다.** 아무 개선도 하지 않은 첫 파이프라인의 점수를 기록하고, 이후 변경은 그 기준선 대비로 판단한다.

## 6. 사용자와 사용 흐름

**사용자** — 개발자 본인 한 명. 다른 사용자를 상정하지 않는다.

**흐름**

```
1. python -m src.cli ingest
   → 데이터 적재 → 청크 분할 → 임베딩 → 색인 저장 (1회)

2. python -m src.cli ask "민감성 피부인데 볼 부위 커버는 어떻게 하나요"
   → 검색 → 근거 확인 → 생성 → 답 + 근거 문단 + 면책 문구

3. python -m src.cli eval
   → QA 10,043쌍 채점 → eval/ 아래에 리포트 저장
```

## 8. 열린 질문

착수 전에 답이 없는 항목이다. 데이터를 받으면 확정한다.

착수 전 질문과 그 답이다 (2026-09-09 확인 완료).

- **`.doc`이 구형 바이너리인가** — 혼재한다. OLE2 5,446 / 실제 docx 718 / RTF 4 / 빈 파일 2. 확장자를 믿을 수 없다.
- **지식데이터 1건의 평균 길이는** — `.json` 3,090개에는 본문이 없다. 메타데이터뿐이다. 색인 대상을 QA 라벨링으로 바꿨다 (D-027 → D-032).
- **QA쌍이 근거 문단 ID를 포함하는가** — ID는 없고 근거 원문이 들어 있다. 자동 채점이 가능해 보였으나 **검색으로 도달할 수 없어 Recall을 폐기했다** (D-029).
- **이용허락범위가 일반 조건과 같은가** — 페이지에 별도 기재가 없어 AI Hub 일반 조건이 적용된다. 상세는 `docs/DATASETS.md`.

## 9. 배포 시 추가되는 요건

현재는 학습용이라 적용하지 않는다. 배포 결정이 나면 `docs/process/SAFETY.md`의 공개 배포 항목이 전부 활성화된다.

- 개인정보 처리 방침
- 의료 조언이 아님을 명시하는 고지
- 데이터셋 출처 표기 (이용 조건)
- 오답 신고 경로
- 저작권자와의 상업 이용 조건 확인
