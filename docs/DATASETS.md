### 분할 파일 병합

AI Hub는 대용량 파일을 `.zip.part*`로 쪼개서 준다. 페이지가 안내하는 병합 명령은 다음과 같다.

```bash
find 폴더경로 -name 파일명.zip.part* -print0 | sort -zt'.' -k2V | xargs -0 cat > 파일명.zip
```

**페이지는 리눅스를 권장하고 윈도우는 WSL 설치를 안내하지만, 이 환경에서는 WSL이 필요 없다.** Git Bash에 GNU coreutils 8.32가 있고 `find`, `sort -zt'.' -k2V`, `xargs -0`, `cat`이 모두 동작하는 것을 확인했다(2026-09-07). WSL 배포판은 설치돼 있지 않으므로 Git Bash로 진행한다.

## 수령 후 확인할 것

`M2-1`에서 처리한다. 다섯 항목을 한 번에 답하는 도구가 `scripts/inspect_dataset.py`에 있다.

```bash
.venv/Scripts/python.exe scripts/inspect_dataset.py
.venv/Scripts/python.exe scripts/inspect_dataset.py --out docs/reports/dataset-inspection.md
```

기본 대상은 `data/raw`다. **이 도구는 원문을 출력하지 않는다.** 30자를 넘는 문자열 값은 길이 통계만 내고, 30자 이하라도 고유값이 20종을 넘으면 나열하지 않는다 (`MEMORY.md` D-024).

### 확인 결과 (2026-09-08, M2-1 완료)

보고서 전문은 `docs/reports/dataset-inspection.md`에 있다.

**파일 구성**

| 종류 | 개수 | 용량 | 내용 |
|---|---|---|---|
| 지식데이터 `.doc` | 6,170 | 543.7 MB | 본문 |
| 지식데이터 `.json` | 3,090 | — | **메타데이터만.** 제목·저자·출처·키워드·토큰수. 본문 없음 |
| QA 라벨링 `.json` | 9,031 | 47.9 MB | Training 8,031 / Validation 1,000 |
| 원본 `.zip` | 27 | 173.8 MB | 압축 해제 전 |

압축 해제 후 전체 765.6 MB(zip 포함), 파일 18,328개.

- [x] **`.doc`이 구형 바이너리인가** — **혼재한다.** 전량 6,245개 기준 OLE2 5,513개, ZIP(실제 `.docx`) 724개, RTF 4개, 빈 파일 4개. 확장자만 보고 파서를 고르면 안 된다. 읽는 방법은 `src/infrastructure/doc_reader.py`에 있다(표준 라이브러리만, 6,237건 전량 추출 성공).
- [x] **지식데이터 1건의 평균 길이** — `.json`에는 본문이 없어 잴 수 없다. QA에 실린 근거 발췌는 평균 170자(10~828자). **`.doc` 본문은 평균 25,608자**(중앙값 19,591자, 289~484,823자)로 발췌의 150배다. 한글 비율은 평균 0.32이고 나머지는 영문·수식·표다.
- [x] **같은 논문이 여러 폴더에 있는가** — **있다.** `지식 데이터` 아래 최상위(`국내석사`, `해외저널` 등 3,122건)와 `사용논문`(1,315건) + `미사용논문`(1,808건)이 같은 파일의 다른 배치다. 전부 읽으면 문서 하나가 두 번 색인된다. `사용논문`만 QA 라벨링에 실제로 쓰였다.
- [x] **QA쌍이 근거를 포함하는가** — 문단 ID는 없지만 **근거 원문이 QA JSON 안에 그대로 들어 있다**(`Source_info1~5.Knowledge Data1~5`). 9,031건 전부 최소 1개, 총 9,181개, 고유 5,921개. 출처 `.doc` 파일명도 함께 있다. **Recall@k 자동 채점이 가능하다.**
- [x] **메타데이터 필드명과 값 체계** — 아래 표.
- [x] **실제 전체 용량** — 765.6 MB.

**QA 라벨링 JSON의 주요 필드**

| 필드 | 내용 |
|---|---|
| `Data_info.SEQ` | `A000137_07_QA1` 형태. 접두 6,308종 |
| `Annotation_info.User Question` | 질문. 평균 356자 |
| `Annotation_info.Makeup Response` | 답변. 평균 499자 |
| `Annotation_info.Recommended Ingredients` / `Ingredients to Avoid` | 권장·회피 성분 |
| `Source_info1~5.Knowledge Data1~5` | 근거 원문 발췌 |
| `Source_info1~5.File Name*_1` | 근거가 나온 `.doc` 파일명 |
| `Human_info` | 연령대, 성별, 메이크업 부위·빈도·목적, 중요 속성 |
| `Skin_info` | 피부 밝기, 상태(지성 등), 고민 상황, 계절 |

**폴더명이 라벨을 담는다** — `TL_민감성 피부_아토피 피부` 형태로 4대 분류와 세부 유형(13종)이 함께 들어 있다.
