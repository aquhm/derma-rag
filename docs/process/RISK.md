# RISK

발생 가능성과 영향을 함께 본다. 완화책은 문서가 아니라 코드나 절차여야 한다.

## 등급

| 등급 | 의미 |
|---|---|
| 높음 | 프로젝트가 목적을 잃거나 실제 피해가 발생 |
| 중간 | 일정이 지연되거나 재작업 발생 |
| 낮음 | 불편하지만 진행 가능 |

## 위험 목록

### R-1 · 지어낸 답변이 조언으로 받아들여진다 — 높음

**시나리오** 근거 없이 생성된 제품 추천을 사용자가 따라 하고 염증이 악화된다.

**완화** 두 게이트(S-2 입력, S-4 출력)를 코드 분기로 강제. 필수 테스트 3종. 프롬프트 문구에 의존하지 않는다.

**잔여 위험** 생성 모델이 근거 문단을 왜곡해 요약할 가능성. 근거 원문을 함께 표시(FR-10)해 사용자가 대조할 수 있게 한다.

### R-2 · 원본 데이터가 저장소에 커밋된다 — 높음

**시나리오** `data/`를 실수로 `git add` 하고 push 한다. 이용약관 위반이며 되돌리기 어렵다.

**완화** `.gitignore` 등록. `data/**` 쓰기에 대한 PreToolUse hook. 테스트에 실데이터를 쓰지 않는 규칙.

**잔여 위험** `git add -f`로 강제하면 뚫린다. 커밋 전 `git status` 확인 습관.

### R-3 · `.doc` 파일을 열 수 없다 — 중간

**시나리오** 구형 바이너리 `.doc`이라 `python-docx`로 안 열린다. 파서를 새로 찾아야 한다.

**완화** M2-1에서 형식을 먼저 확인한다. `.json`만으로 진행 가능한지 병행 검토.

**잔여 위험** 지식데이터가 `.doc`에만 있으면 우회 불가. LibreOffice CLI 변환이 필요할 수 있다.

### R-4 · 데이터셋 이용허락범위가 예상과 다르다 — 중간

**시나리오** 저작권자가 민간 기업(㈜데이터쿡)이라 일반 AI Hub 조건과 다르다. 학습 결과물 활용에 제약이 있을 수 있다.

**완화** M0-2에서 신청 전에 확인한다. 확인 결과를 `docs/DATASETS.md`에 기록.

**잔여 위험** 확인이 늦어지면 작업 후 재검토가 필요할 수 있다.

### R-5 · 전체 임베딩이 중단된다 — 중간

**시나리오** 9,377건 임베딩 중 오류로 끊긴다. 중간 저장이 없으면 처음부터 다시.

**완화** 배치 처리 + 체크포인트 저장을 FR-3에 요구사항으로 명시.

### R-6 · 생성이 너무 느려 작업이 막힌다 — 중간

**실현됨 (2026-09-07)** `gemma4:31b` 19GB가 VRAM 16GB를 초과해 RAM 스필. 응답 하나에 189초가 걸렸고 쓸 수 있는 답이 나오지 않았다. `ERRORS.md` E-001.

**완화** 어댑터 교체가 `composition.py` 한 줄이다. `qwen2.5:3b`로 즉시 내릴 수 있다.

### R-7 · 검색 품질이 낮은데 원인을 모른다 — 중간

**시나리오** 답이 이상한데 검색 문제인지 생성 문제인지 구분이 안 된다.

**완화** Recall@k와 답변 정확도를 분리 측정(FR-12, `MEMORY.md` D-008). 기준선 기록 후 한 번에 하나씩만 변경.

### R-8 · 학습 목적이 흐려진다 — 중간

**시나리오** 빨리 돌아가게 하려고 프레임워크를 넣고, 결국 RAG가 아니라 프레임워크 사용법을 배우게 된다.

**완화** `MEMORY.md` D-003으로 명시적 금지. CLAUDE.md 5영역에 반복 기재.

**주의** 이 위험은 기술이 아니라 판단의 문제다. 조급해질 때 발동한다.

### R-9 · 청크 경계가 문맥을 끊는다 — 낮음

**시나리오** Recall은 높은데 답변 품질이 낮다.

**완화** 오버랩을 초기값에 포함. M3-1에서 측정 조정. `ERRORS.md`에 진단 순서 기록.

### R-10 · 한글이 깨진다 — 낮음

**시나리오** Windows 기본 인코딩 CP949로 파일이 읽혀 한글이 깨진다.

**완화** `encoding="utf-8"` 명시를 `docs/guidelines/00-common.md`에 규칙화.

## 다루지 않는 위험

| 위험 | 이유 |
|---|---|
| 서버 다운, 트래픽 급증 | 서비스가 아니다 |
| 사용자 데이터 유출 | 사용자가 없다. 이력을 저장하지 않는다(S-7) |
| 비용 초과 | 로컬 모델만 쓴다 |
| 모델 API 변경 | 로컬 Ollama라 버전을 고정할 수 있다 |
