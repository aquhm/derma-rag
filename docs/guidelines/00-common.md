# 00 · 공통 지침

모든 레이어에 적용된다. 레이어별 지침은 이 문서를 전제로 한다.

## 코드를 쓰기 전에

1. 어느 레이어에 속하는 코드인지 정한다.
2. 해당 레이어 지침(`01`~`04`)을 읽는다.
3. 의존 방향이 안쪽으로만 향하는지 확인한다 (`docs/ARCHITECTURE.md` §2).

## 명명

| 대상 | 규칙 | 예 |
|---|---|---|
| 모듈 | `snake_case` | `answering.py` |
| 클래스 | `PascalCase` | `OllamaEmbedder` |
| 함수·변수 | `snake_case` | `build_index` |
| 상수 | `UPPER_SNAKE` | `DEFAULT_TOP_K` |
| 포트(Protocol) | 역할 명사 | `Embedder`, `VectorIndex` |
| 어댑터 | 구현체 + 역할 | `OllamaEmbedder`, `NumpyVectorIndex` |

한국어 도메인 용어는 영어로 옮긴다. `민감성 피부` → `sensitive`. 매핑은 `domain/models.py`에 한 곳으로 모은다.

## 타입 힌트

모든 공개 함수에 타입 힌트를 붙인다. 타입 검사기를 돌리지 않더라도 읽는 사람에게 설계 의도가 전달된다.

```python
def search(self, vector: list[float], k: int) -> list[Evidence]: ...
```

## 인코딩

**모든 파일 입출력에 `encoding="utf-8"`을 명시한다.** Windows 기본값은 CP949라서 명시하지 않으면 한글이 깨진다.

```python
with open(path, encoding="utf-8") as f: ...
path.write_text(content, encoding="utf-8")
```

## 예외와 실패

| 상황 | 처리 |
|---|---|
| 프로그래머 실수 (잘못된 인자) | 예외를 던진다 |
| 예상되는 도메인 실패 (근거 없음) | **값으로 반환한다.** `Refusal` |
| 외부 시스템 실패 (Ollama 응답 없음) | 어댑터에서 잡아 도메인 타입으로 변환 |

근거 없음을 예외로 처리하지 않는 이유는 `docs/ARCHITECTURE.md` §3에 있다. 예외는 안 잡으면 흘러가고, 값은 반드시 분기해야 한다.

## 주석

무엇을 하는지는 코드가 말한다. 주석은 **왜 그렇게 했는지**를 적는다.

```python
# 나쁨: 코사인 유사도를 계산한다
# 좋음: 정규화를 미리 해두면 내적만으로 코사인이 나온다. 9,377건 전수 계산이라 이 차이가 크다
```

결정과 얽힌 주석은 근거를 링크한다.

```python
# 벡터 DB를 쓰지 않는 이유는 MEMORY.md D-004
```

## 로그

| 남겨도 되는 것 | 남기면 안 되는 것 |
|---|---|
| 단계 이름, 처리 건수, 소요 시간 | **원본 데이터 텍스트** |
| 유사도 점수, 선택된 청크 ID | 사용자 질문 원문 (개인 건강 정보일 수 있음) |
| 오류 종류 | API 키, 파일 절대 경로 |

원문을 확인해야 할 때는 로그가 아니라 디버거를 쓴다.
