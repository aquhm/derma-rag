# 04 · interface 레이어

경로: `src/interface/**`

## 역할

사용자 진입점. 이 프로젝트에서는 CLI 하나다.

## 의존 규칙

전 레이어를 import 할 수 있다. 다만 조립은 `composition.py`에 맡기고 직접 어댑터를 만들지 않는다.

## CLI 명령

```
python -m src.cli ingest             1~4단계
python -m src.cli ask "질문"          5~6단계
python -m src.cli eval               채점
```

`argparse`를 쓴다. 외부 CLI 라이브러리를 넣지 않는다.

## 출력 규칙

### 답변 출력에 반드시 포함할 것

세 가지가 빠지면 안 된다.

1. **답변 본문**
2. **근거 문단** — 어느 청크에서 나왔는지. 사용자가 원문을 확인할 수 있어야 한다
3. **면책 문구** — `SafetyPolicy`가 제공하는 고정 문구

근거 표시를 생략하지 않는다. 근거를 보여주는 것이 이 시스템의 존재 이유다.

### 거부 출력

`Refusal`을 받으면 사유를 그대로 보여준다. "죄송합니다" 같은 사과 문구를 덧붙이지 않는다.

```
답할 수 없습니다.
사유: 데이터셋에서 관련 근거를 찾지 못했습니다 (최고 유사도 0.21 < 임계값 0.35).
```

**임계값과 실제 점수를 함께 보여준다.** 학습 목적이므로 왜 거부됐는지가 보여야 한다.

### 진행 표시

`ingest`는 오래 걸린다. 단계와 건수를 출력한다.

```
[1/4] 문서 적재 ... 9,377건
[2/4] 청크 분할 ... 24,113개
[3/4] 임베딩 ... 3,200 / 24,113
```

### 인코딩

Windows 콘솔에서 한글이 깨지지 않도록 표준 출력 인코딩을 확인한다. 파일 출력은 항상 `encoding="utf-8"`.

## 종료 코드

| 코드 | 의미 |
|---|---|
| 0 | 정상 |
| 1 | 사용자 입력 오류 |
| 2 | 외부 시스템 오류 (Ollama 연결 실패 등) |

## 하지 않는 것

- 비즈니스 로직 — `application`의 일이다
- 프롬프트 조립 — `application`의 일이다
- 직접 HTTP 호출 — `infrastructure`의 일이다
- 웹 UI — M4 선택 항목 (`docs/ROADMAP.md`)

## 테스트

스모크 테스트만 둔다. 각 명령이 오류 없이 끝나는지 확인한다. 로직 검증은 `application` 테스트에서 이미 했다.
